# 보건실 서버 설치·운영 안내

접수 태블릿·간호사 PC·근로학생 PC가 **같은 기록을 함께 보도록** 보건실 PC 한 대에서 작은 서버를 돌립니다.
데이터는 학교 밖으로 나가지 않고 그 PC 안의 파일 하나에만 저장됩니다.

```
                [보건실 PC — 서버]
                기록 파일 data/health-center.sqlite
                        ↑ 같은 학교 네트워크
        ┌───────────────┼───────────────┐
   접수 태블릿      간호사 PC       근로학생 PC
   (브라우저)       (브라우저)       (브라우저)
```

태블릿과 근로학생 PC에는 **아무것도 설치하지 않습니다.** 브라우저에서 서버 주소만 열면 됩니다.

## 1. 서버 PC 고르기

- 보건실 운영 시간 동안 켜져 있는 PC (간호사 PC를 그대로 써도 됩니다)
- 태블릿과 같은 와이파이/랜에 연결
- 사양은 상관없습니다. 하루 수십 건 기록은 아주 가볍습니다

**절전 모드로 자면 접수가 멈춥니다.** 설정 → 시스템 → 전원에서 화면 끄기만 두고 `절전 모드`는 `안 함`으로 두세요.

## 2. 설치 (서버 PC에서 한 번만)

1. [Node.js 24 LTS](https://nodejs.org/) 설치 — `node --version`이 `v24.` 로 시작하면 됩니다
2. 이 저장소를 내려받아 폴더를 엽니다
3. 아래를 실행합니다

```bash
npm ci
npm run serve
```

`npm run serve`는 화면을 빌드하고 서버를 켭니다. 창에 접속 주소가 뜹니다.

```
건강진료센터 접수 서버가 시작되었습니다.
  기록 파일: C:\...\data\health-center.sqlite
  접속 주소: http://localhost:8080
  접속 주소: http://192.168.0.31:8080
```

`192.168.…` 로 시작하는 주소가 **태블릿·근로학생 PC에서 열 주소**입니다. 이 주소를 각 기기 브라우저 즐겨찾기(태블릿은 홈 화면 추가)에 넣어 두세요.
접수 태블릿은 주소 끝에 `?kiosk=1`을 붙이면 담당자 버튼이 숨겨집니다 — `http://192.168.0.31:8080/?kiosk=1`

## 3. 방화벽 열기 (서버 PC에서 한 번만)

Windows 방화벽이 다른 기기의 접속을 막습니다. 관리자 권한 PowerShell에서:

```powershell
New-NetFirewallRule -DisplayName "건강진료센터 접수" -Direction Inbound -LocalPort 8080 -Protocol TCP -Action Allow -Profile Private
```

`-Profile Private`이라 학교 네트워크가 `개인 네트워크`로 잡혀 있어야 합니다. 공용으로 잡혀 있으면 설정 → 네트워크에서 바꿔 주세요.

## 4. 자동 시작 등록 (권장)

PC를 껐다 켜도 서버가 다시 뜨게 합니다. 관리자 권한 PowerShell에서 저장소 폴더로 이동한 뒤:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-autostart.ps1
```

등록을 지우려면 `-Remove` 를 붙여 다시 실행하면 됩니다.

## 5. 첫 사용 순서

1. 서버 PC 브라우저에서 `http://localhost:8080` 열기
2. `담당자 화면` → **관리자 PIN 최초 설정** (숫자 6~12자리)
3. 화면에 **복구 코드**가 한 번만 표시됩니다. 종이에 적어 보건실 서랍에 보관하세요. PIN을 잊으면 이 코드로만 재설정할 수 있습니다
4. 태블릿에서 접속 주소를 열고 시험 접수를 한 건 넣어 봅니다
5. 간호사 PC 담당자 화면에 그 접수가 바로 뜨는지 확인합니다

PIN은 **서버에 저장**됩니다. 기기마다 따로 설정하지 않고, 세 기기가 같은 PIN을 씁니다.

## 6. 백업

기록은 `data/health-center.sqlite` 파일 하나에 들어 있습니다. 서버를 잠깐 끄고 `data` 폴더를 통째로 복사해 두면 그게 백업입니다.

권장: **주 1회**, 학기 말에 한 번. USB나 학교 공용 드라이브에 날짜를 붙여 보관하세요. (`data-2026-09-04` 처럼)

서버를 끄지 않고 복사하면 `-wal`, `-shm` 파일까지 세 개를 함께 복사해야 합니다.

## 7. 자주 겪는 문제

| 증상                                             | 확인할 것                                                                              |
| ------------------------------------------------ | -------------------------------------------------------------------------------------- |
| 태블릿에서 화면이 안 열림                        | 서버 PC가 켜져 있는지, 같은 와이파이인지, 방화벽 규칙(3번)을 넣었는지                  |
| 접속 주소가 바뀜                                 | 공유기가 IP를 새로 준 경우입니다. 공유기에서 서버 PC에 고정 IP를 주면 다시 안 바뀝니다 |
| `포트 8080을 이미 다른 프로그램이 쓰고 있습니다` | `set HC_PORT=8090` 처럼 포트를 바꿔 실행하고, 방화벽 규칙도 같은 번호로 다시 만드세요  |
| 담당자 화면이 자꾸 잠김                          | 5분 동안 아무 조작이 없으면 잠깁니다. 의도된 동작입니다                                |
| PIN을 잊음                                       | 최초 설정 때 받은 복구 코드로 재설정합니다                                             |

## 8. 알아 둘 점

- **서버 PC가 꺼져 있으면 접수도 멈춥니다.** 기록이 한 곳에만 쌓이게 해서 중복·충돌을 원천적으로 없앤 선택입니다. 서버가 멈춘 동안에는 종이로 받고 나중에 담당자 화면에서 입력하시면 됩니다
- 보관 기간(30일)이 지난 기록은 서버가 한 시간에 한 번 자동으로 지웁니다
- 담당자 화면에서 한 조작은 감사 기록에 남습니다 (담당자 화면 → 감사 기록)
- 이 서버는 **학교 네트워크 안에서만** 접속됩니다. 인터넷에 열지 마세요. 열려면 개인정보 처리방침·위탁 검토가 따로 필요합니다
